这是一个 [Carpet mod](https://github.com/gnembon/fabric-carpet) 的扩展模组，面向技术生存，提供玩法调整、资源可再生、生存便利以及性能优化相关规则，并支持多个 Minecraft 版本。

默认配置不会改变原版玩法机制：所有玩法规则默认关闭；仅用于可选客户端能力协商的 `ddsNetworkProtocol` 默认开启，未安装 DDS 客户端的玩家仍可正常连接。

与对应 Minecraft 版本的 Fabric Carpet 一起使用即可。

## 支持版本

Carpet DDS Addition 使用多版本源码及构建结构。

当前构建目标覆盖 Minecraft **1.14.4 至 26.2**，包括：

`1.14.4` · `1.15.x` · `1.16.x` · `1.17.x` · `1.18.x` · `1.19.x` · `1.20.x` · `1.21.x` · `26.1.x` · `26.2`

部分规则仅支持较新的 Minecraft 版本，具体最低版本请查看[规则文档](docs/rules-zh_cn.md)。
