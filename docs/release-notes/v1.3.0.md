# Carpet DDS Addition 1.3.0

## 中文

本版本新增三项面向技术生存与服务器使用的 Carpet 规则，并进一步完善多版本兼容、规则行为以及项目构建基础设施。

### 新增规则

#### 更好的方块掉落自动入包（`directBlockDrops`）

玩家破坏方块时，将与本次操作相关的物品掉落优先直接送入玩家背包。

主要特性：

- **重点支持竹子、仙人掌、甘蔗、脚手架等因连锁破坏或失去支撑产生的同步掉落；**
- 支持玩家直接破坏方块产生的掉落；
- 支持被破坏容器释放的内部物品；
- 支持 DDS `rightClickHarvest` 产生的同步收获掉落；
- 物品仍按照原版战利品与掉落逻辑生成，本规则只改变生成后的物品去向；
- 背包空间不足时，无法放入的部分仍按照原版机制掉落在世界中；
- 仅追踪与当前玩家操作相关的掉落链，不会持续吸收后续无关掉落。

默认关闭。

---

#### 安全旁观模式（`commandCamera`）

为生存玩家提供受保护的临时旁观 Camera 模式。

主要命令：

- `/c`：进入或退出 Camera 模式；
- `/c back`：返回进入 Camera 模式时保存的位置，并继续保持旁观状态；
- `/c follow <玩家>`：进入 Camera 模式并观察指定玩家，或切换当前观察目标。

主要特性：

- 进入 Camera 模式时保存玩家原始位置及相关状态；
- 只有符合安全条件的生存玩家才能进入；
- 退出 Camera 模式时先返回原始位置，再恢复为生存模式；
- 防止利用旁观模式改变生存模式下的实际位置；
- 对断开连接、异常会话等情况进行状态保护与恢复。

支持 Minecraft `1.16.5–26.2`。

默认关闭。

---

#### 村民雷击不变女巫（`noVillagerWitchConversion`）

开启后，村民被闪电击中时不会转化为女巫。

该规则：

- 仅阻止村民因雷击转化为女巫；
- 不取消闪电本身；
- 不影响闪电造成的其他原版效果；
- 不改变其他生物受到闪电影响时的原版行为；
- 关闭规则后恢复原版村民雷击转化机制。

支持 Minecraft `1.14.4–26.2`。

默认关闭。

## English

This release adds three new Carpet rules focused on technical survival and server-side convenience, while further improving multi-version compatibility, rule behavior, and the project's build infrastructure.

### New Rules

#### Direct Block Drops (`directBlockDrops`)

Item drops associated with a player's block-breaking action are sent directly into the player's inventory whenever possible.

Main features:

- Supports drops produced directly by player block breaking;
- Supports synchronous chain drops caused by bamboo, cactus, sugar cane, scaffolding, and similar blocks breaking or losing support;
- Supports items released from broken container blocks;
- Supports synchronous harvest drops produced by DDS `rightClickHarvest`;
- Items are still generated according to vanilla loot and drop logic; this rule only changes where the resulting items are delivered;
- Items that cannot fit into the player's inventory continue to drop normally into the world;
- Only drop chains associated with the current player action are tracked, avoiding the collection of unrelated later drops.

Disabled by default.

---

#### Safe Spectator Camera (`commandCamera`)

Provides Survival-mode players with a protected temporary spectator Camera mode.

Main commands:

- `/c` — enter or leave Camera mode;
- `/c back` — return to the position saved when Camera mode was entered while remaining in spectator mode;
- `/c follow <player>` — enter Camera mode and spectate a specified player, or switch the current spectating target.

Main features:

- Saves the player's original position and relevant state when Camera mode is entered;
- Only eligible Survival-mode players in a safe state can enter;
- Returns the player to the original position before restoring Survival mode;
- Prevents spectator movement from being used to permanently relocate a Survival-mode player;
- Provides state protection and recovery for disconnects and invalid Camera sessions.

Supported on Minecraft `1.16.5–26.2`.

Disabled by default.

---

#### No Villager Witch Conversion (`noVillagerWitchConversion`)

Prevents villagers from transforming into witches when struck by lightning.

This rule:

- Only prevents villager-to-witch conversion caused by lightning;
- Does not cancel the lightning strike itself;
- Preserves all other vanilla lightning effects;
- Does not change vanilla lightning behavior for other entities;
- Restores vanilla villager lightning conversion behavior when the rule is disabled.

Supported on Minecraft `1.14.4–26.2`.

Disabled by default.

### Improvements and Fixes

- Improved the cross-version implementation of passive mob natural spawning control;
- Improved integration between `rightClickHarvest` and direct block drops;
- Improved compatibility between legacy and modern Carpet rule APIs;
- Refined several rule and compatibility-layer implementations;
- Reorganized the Chinese README and rule documentation structure;
- Updated rule version support information and related documentation.

### Multi-Version Infrastructure

- Improved the multi-version build chain covering Minecraft `1.14.4` through `26.2`;
- Added full bidirectional preprocessing support between traditionally mapped source and unobfuscated Minecraft 26.x source;
- Supports all four preprocessing conversion paths:
    - mapped → mapped;
    - mapped → unobfuscated;
    - unobfuscated → mapped;
    - unobfuscated → unobfuscated;
- Added stronger reversibility validation for preprocessed source;
- Added build-time validation for unsafe `//$$` conditional indentation;
- Successfully validated all 25 supported Minecraft build targets;
- Successfully validated a complete `1.15.2 → 26.2 → 1.15.2` source round trip with no resulting Git source differences;
- Added an automated preprocessing round-trip verification workflow to reduce the risk of source corruption during future multi-version development.

### Supported Versions

Carpet DDS Addition currently provides build targets covering Minecraft:

`1.14.4` through `26.2`

Some rules have their own minimum or maximum supported Minecraft versions. See the rule documentation for details.
