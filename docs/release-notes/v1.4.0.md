### 新增规则

#### 撤销与重做 (`undoRedo`)

为 Minecraft `1.21.9+` 增加面向创造模式玩家的服务端 Undo/Redo 系统。

基本命令：

```text
/undo
/redo
```

客户端安装DDS还可以使用：

```text
Ctrl+Z       撤销
Ctrl+Alt+Z   重做
```

具体使用范畴可留意后续视频讲解。该规则仅允许创造模式玩家使用。

---

#### 爆炸不破坏方块 (`explosionNoBlockDamage`)

允许针对指定类型的爆炸关闭方块破坏。

---

#### 禁止重生方块爆炸 (`noRespawnBlockExplosion`)

阻止床和重生锚在无法正常设置重生点的维度中发生爆炸。

---

### 功能优化

#### 安全旁观模式 (`commandCamera`)

- 增加 Camera 模式下的虚空保护；
- 进一步完善异常情况下的安全返回逻辑。

## English

### New Rules

#### Undo and Redo (`undoRedo`)

Adds a server-side Undo/Redo system for Creative-mode players on Minecraft `1.21.9+`.

Basic commands:

```text
/undo
/redo
```

The DDS client is optional. The commands can be fully used with DDS installed only on the server.

When compatible DDS versions are installed on both the client and server and `ddsNetworkProtocol` is enabled, the following shortcuts are also available:

```text
Ctrl+Z       Undo
Ctrl+Alt+Z   Redo
```

More detailed usage scenarios may be covered in a future video guide.
This rule is only available to Creative-mode players.

---

#### Explosion No Block Damage (`explosionNoBlockDamage`)

Allows block destruction to be disabled for selected explosion types.

---

#### No Respawn Block Explosion (`noRespawnBlockExplosion`)

Prevents beds and respawn anchors from exploding in dimensions where they cannot normally set a respawn point.

---

### Improvements

#### Safe Spectator Camera (`commandCamera`)

- Added void protection while in Camera mode;
- Further improved safe return behavior for abnormal situations.
