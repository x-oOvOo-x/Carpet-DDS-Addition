# Carpet DDS Addition 1.8.0

本次更新集中完善假人交互、快速容器访问、自动补货、动态配方及规则管理，并进一步优化多版本兼容性与稳定性。

### ✨ Added & Improved / 新增与优化

- **规则管理重构**：建立 CDA 独立规则管理器，新增 `/cda` 命令，兼容旧命令并支持配置自动迁移。(Independent rule management with legacy compatibility and configuration migration.)

- **假人交互增强**：统一 GCA/Org 背包会话、权限与动作控制，完善精确停止、末影箱 27/54 格和远程操作。(Improved fake-player inventory sessions, actions and Ender Chest access.)

- **客户端职责迁移**：客户端增强统一交由 DDS Tweak 负责，CDA 保留服务端逻辑、权限验证及兼容协议。(Moved client enhancements to DDS Tweak while retaining server authority.)

- **自动补货**：新增 `autoRestock` 多来源自动补货，支持背包、潜影盒、收纳袋和本人末影箱，并适配全部 21 个版本。(Added multi-source automatic restocking across 21 versions.)

- **动态配方**：优化切石机配方热切换、混凝土粉末熔炼及 JEI/REI 同步，清理新版 Minecraft 已原生支持的重复配方。(Improved dynamic recipes and JEI/REI synchronization.)

- **直接掉落入包**：完善收获、剪切、刷取及脚手架等连锁破坏掉落的归属判断与异常处理。(Improved direct item drops and delayed block-drop attribution.)

- **Camera 功能**：扩展 `/c tp` 坐标、玩家和跨维度传送，修复 `/c follow` 跨维度及末地返回后的恢复问题。(Expanded Camera teleportation and fixed cross-dimension follow recovery.)

### 🐛 Fixed / 修复

- **QCA 与容器兼容性**：修复物品超量转移、末影箱归属错误、权限失效及 27/54 格容量异常，增强 AMS 新旧版本与嵌套容器兼容。(Fixed QCA transfer, ownership, permission and container-capacity issues.)

### 🔧 Compatibility & Maintenance / 兼容性与维护

- **版本与构建优化**：新增 Minecraft 26.3 支持，维护全部 21 个版本的构建，完善协议兼容、Mixin 检查及发布流程。(Added Minecraft 26.3 support and improved multi-version builds and release validation.)

### 📌 Notes / 注意事项

部分客户端增强需要搭配 DDS Tweak。本版本不包含仍在开发的假人独立加载/模拟距离控制、共享材料智能取材及尚未完成的单人档 Undo 修复。
